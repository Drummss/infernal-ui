## 0.3.0

### Minor Changes

- 34dfec6: Add polymorphic Icon and Link components and a built-in yellow accent theme.

  sizing. Link provides theme-aware colors and keyboard focus styles for anchors
  and router links. The root IconProps export now describes the new Icon primitive;
  use SvgIconProps for the existing CheckIcon and ChevronDownIcon props.
